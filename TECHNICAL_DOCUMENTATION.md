## 1. КОНЦЕПЦИЯ И ЦЕЛИ

### 1.1 Назначение

Дашборд предназначен для оперативного мониторинга экологической обстановки в Республике Казахстан в разрезе:
- **Обращений граждан** (eObr) — объём, характер, исполнительская дисциплина
- **Промышленного мониторинга** (НБД СОС) — выбросы в атмосферу, сбросы сточных вод, факельное сжигание
- **Спутникового мониторинга** (КГС) — незаконные рубки, самозахваты, карьеры, свалки
- **Медиамониторинга** — новости из официальных СМИ и Telegram-каналов

### 1.2 Аудитория

| Пользователь | Задача |
|---|---|
| Руководство МЭПР | Стратегические KPI, сравнение регионов |
| Аналитики | Drill-down по категориям, кросс-фильтрация |
| Пресс-служба | Мониторинг публикаций в СМИ |
| Территориальные органы | Фильтрация по своему региону |

### 1.3 Принцип работы

Дашборд работает как **статическое одностраничное приложение (SPA)**:
1. Python-скрипт обрабатывает исходные CSV → генерирует JSON-файлы
2. JSON-файлы публикуются вместе с HTML на хостинге Vercel
3. Браузер загружает JSON и рендерит чарты на лету без обращения к базе данных

Это обеспечивает: высокую скорость загрузки, работу без VPN, отсутствие риска утечки сырых данных.

### 8.3 ИИ-ассистент

Чатбот на базе **Anthropic Claude claude-3-haiku-20240307** встроен в дашборд.  
API-ключ хранится в переменной окружения Vercel `ANTHROPIC_API_KEY` (не в коде).  
Запросы проксируются через `api/proxy.js` — ключ никогда не передаётся в браузер.

**Контекст ИИ:** ассистент получает текущие данные дашборда (summary.json) и может отвечать на вопросы о конкретных цифрах, регионах, предприятиях.
